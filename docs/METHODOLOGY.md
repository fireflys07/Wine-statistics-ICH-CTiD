# Методические ограничения

- Случайная величина определяется через случайный выбор объекта/наблюдения и числовой результат. Невозможность написать формулу сама по себе не доказывает случайность. Укажите эксперимент и источники вариабельности; не приписывайте статьям непроверенные утверждения о настроении или температуре.
- quality — дискретная порядковая оценка. Среднее допустимо обсуждать с явным допущением о числовой шкале; дополнительно показывайте частоты и медиану.
- Датасет можно считать конечной генеральной совокупностью для учебного сэмплирования. Он не является всеми винами мира; внешнее обобщение ограничено дизайном сбора.
- С возвращением наблюдения при равномерном независимом выборе имеют одинаковое распределение. Без возвращения они зависимы; для среднего учитывайте конечную совокупность: Var(mean)=(1-n/N)S²/n, где S² имеет знаменатель N-1.
- Состоятельность — асимптотическое свойство модели, график только иллюстрирует его. Повторяйте выборки при нескольких n, показывайте смещение, RMSE и разброс. Для конечной совокупности без возвращения ошибка среднего исчезает при n=N.
- Welch t-test проверяет равенство средних при своих предпосылках. Mann–Whitney не является общим тестом равенства средних; интерпретация как сдвига требует дополнительных предпосылок. Для quality учитывайте совпадающие ранги.
- Не задавайте заранее результат гипотезы. Укажите H0/H1, alpha, эффект, доверительный интервал, p-value и ограничения. Различие красного и белого не доказывает причинное влияние цвета.
- Нулевая корреляция и p>alpha не доказывают независимость. Покажите диаграммы, Pearson/Spearman с предпосылками, проверьте связи отдельно по типам вина; учитывайте смешение групп и множественные проверки.
- Z-преобразование даёт нулевое среднее и единичный масштаб, но не делает распределение нормальным. Если исходная модель нормальная, объясните переход к стандартной нормальной.
- Выбор наиболее дисперсионных признаков зависит от единиц. Для PCA обоснуйте стандартизацию. Эллипсы 1/2/3 не имеют автоматически покрытия 68/95/99.7% в двумерном случае.
- Разделяйте обучение и тестирование модели до подбора преобразований. Не используйте quality как входной признак её же предсказания.
- Сравнивайте генератор с выбранной моделью и исходными данными отдельно. Один p-value не доказывает совпадение распределений; нужны метрики, допуски, размеры выборок и диагностика.
