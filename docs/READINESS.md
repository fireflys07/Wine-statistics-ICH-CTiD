## Техническая проверка

- Оба исходных CSV загружены с проверкой SHA-256.
- Все 69 вычислительных ячеек объединённого ноутбука последовательно выполнены в свежем процессе IPython; ошибок и stderr в сохранённых результатах нет.
- Запуск отдельного ядра через nbclient в этой среде заблокирован ограничениями сокетов; поэтому такой запуск здесь не подтверждён. Команда для обычного Jupyter сохранена.
- 20 автотестов прошли.
- Версия для сдачи не содержит кодовых ячеек; графики встроены в файл, таблицы сохранены.
- Ссылки на разделы и локальные файлы проверены при сборке.
- Измерения времени генераторов зависят от машины и повторного запуска.

Полные дубликаты не пересекают границу train/test во втором спринте. Первый спринт использует весь набор, поэтому test нельзя называть ранее не просмотренными данными для исследования в целом. Корреляции не доказывают причинность; результаты не переносятся автоматически на все вина.
