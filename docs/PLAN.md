# План и ответственность

Имена/GitHub-логины назначаются командой. Роли можно совмещать в рамках разрешённого состава.

| Роль | Основные файлы | Обязательный результат |
|---|---|---|
| 1: эмпирик, интегратор | sprint1/01_quality.ipynb; Lab01.ipynb | quality, сравнение типов вина, сборка выводов |
| 2: физхимический анализ | sprint1/02_alcohol.ipynb | alcohol, связь с quality |
| 3: физхимический анализ | sprint1/03_volatile_acidity.ipynb | volatile_acidity, связь с alcohol |
| 4: генератор и общий код | sprint2/01_generator.ipynb; src/; tests/ | генератор, проверка метрик, общий эксперимент состоятельности |
| КТвД | итоговый ноутбук, рисунки | оглавление, якоря, формулы, масштабы, единый стиль, скрытие кода |

## Sprint 1 — недели 1–2
- [ ] Зафиксировать источник, единицу наблюдения, три величины и состав команды.
- [ ] Получить данные; описать схему, пропуски, дубликаты и ограничения охвата.
- [ ] Для каждой величины: природа случайности, EDA, распределение, преобразования.
- [ ] Выборки с возвращением и без; сравнение статистик и повторные эксперименты состоятельности.
- [ ] Зависимости, минимум одна заранее сформулированная гипотеза, величина эффекта и интервалы.
- [ ] Собрать все выводы и таблицу критериев в итоговом ноутбуке.

## Sprint 2 — недели 3–4
- [ ] Выбрать модель распределения по результатам Sprint 1 и алгоритм генератора.
- [ ] Самостоятельно написать математическое обоснование со ссылками.
- [ ] Реализовать генератор, воспроизводимость, автотесты, сравнение реальных и синтетических данных.
- [ ] Сравнить дополнительный алгоритм при наличии времени.
- [ ] КТвД: навигация, стиль, единицы, LaTeX; опционально marimo и интерактивный генератор.
- [ ] Проверить выполнение итогового ноутбука в чистой среде.

## Дополнительные блоки — требуют подтверждения задания
L1/L2/L∞, линии уровня и kNN без sklearn — роль 2.
Ковариации, разложение 2×2 и эллипсы — роль 3.
PCA, регрессия, RMSE/MAE/R² — роль 4.
Эти блоки отсутствуют в присланных требованиях Lab01 и не заменяют обязательную статистику.
