# Сборка Lab01

Объединены main, sprint2/models и Designer. Ветка sprint2/data-split уже входит в историю sprint2/models.
Исходная история сохранена двумя merge-коммитами. Новое исследование задним числом не создавалось.

## Что входит

- Один исполняемый `notebooks/Lab01.ipynb`: оба спринта, оглавление, выводы и таблицы критериев.
- Рабочие ноутбуки участников с общей загрузкой CSV из `data/raw/`.
- Модели, два генератора, автотесты и сайт из отдельных веток.
- Загрузка данных с проверкой SHA-256, повторная сборка и обновление показателей сайта.
- Сводные таблицы первого спринта в `reports/tables/`.

## Исправления при сборке

- Убраны установки пакетов из ячеек и зависимость от загрузки через Colab.
- Добавлены недостающие зависимости и единые настройки графиков.
- В AIC для alcohol учитываются два свободных параметра; фиксированный loc не штрафуется.
- Для кислотности исправлена конечная поправка при выбранном определении дисперсии.
- Удалена ссылка на неопределённый corr_result в проверке SO₂.
- ECDF учитывает повторяющиеся значения; плотность и накопленная вероятность имеют отдельные оси.
- Обычный p-value KS после подгонки параметров больше не используется как формальный тест.
- Убраны неподтверждённые причинные объяснения и утверждение о принципиальной невозможности детерминированной модели.
- Разделены классификация по 12 признакам и регрессия по одному alcohol.
- В итогах сохранено смещение генератора на test. Совпадение распределений не заявлено.
- Исправлено переполнение списка выбора на узком экране сайта.

Обоснования методов генерации перенесены из sprint2/models. Перед сдачей авторы должны проверить и понимать эти разделы.

## Ограничения и оставшиеся части

- Test второго спринта исключён из обучения, но весь датасет уже использовался в EDA первого спринта.
- Полные повторы сгруппированы при разбиении. Идентификаторов партий нет, поэтому независимость новых вин не гарантирована.
- Официальные cat_id и coeff пока отсутствуют; баллы не присвоены.
- Нет отдельного датасета КТвД, marimo, обзора восьми алгоритмов и проверки автокорреляции генератора.
- `notebooks/extensions/01_geometry_models.ipynb` остаётся исходным планом. Реализованные дополнения находятся в основных разделах; отдельный PCA не заявлен.
- Состав команды и допустимый формат объединения участников нужно сверить с заданием. В исходном плане перечислено четыре роли инфохимиков.
