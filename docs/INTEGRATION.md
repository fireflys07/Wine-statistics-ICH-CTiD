# Сборка Lab01

Объединены main, sprint2/models и Designer. Ветка sprint2/data-split уже входит в историю sprint2/models.
Исходная история сохранена двумя merge-коммитами.

## Что входит

- Один исполняемый `notebooks/Lab01.ipynb`: оба спринта, оглавление, выводы и таблицы критериев.
- Рабочие ноутбуки участников с общей загрузкой CSV из `data/raw/`.
- Модели, два генератора, автотесты и сайт из отдельных веток.
- Загрузка данных с проверкой SHA-256, повторная сборка и обновление показателей сайта.
- Сводные таблицы первого спринта в `reports/tables/`.
