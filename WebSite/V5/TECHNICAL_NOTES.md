# STAT LAB — технические заметки

## Архитектура

```text
index.html → core.js → components.js → generator-model.js → dependence.js → inference.js → random-utils.js → data-loader.js → frequency-statistics.js → statistics.js → data.js → app.js
                         │          ├─ рендер разделов
data/*.csv ── fetch ─────┴──────────├─ интерактивные эксперименты
                                    └─ SVG-графики и расчёты
```

- `data.js` задаёт структуру лабораторной и заранее рассчитанные учебные материалы.
- CSV — источник сырых наблюдений Wine Quality для интерактивных экспериментов.
- `app.js` пока объединяет состояние, DOM, парсинг CSV, статистику, генераторы и визуализацию.
- `core.js` содержит независимые от DOM утилиты; в первой итерации туда вынесено экранирование HTML.
- `statistics.js` — независимый от DOM модуль базовой описательной статистики с проверкой числовой выборки.
- `data-loader.js` — независимый от DOM разбор CSV Wine Quality; `app.js` использует его через совместимый адаптер.
- `random-utils.js` — воспроизводимая случайность, CDF и генерация дискретных выборок.
- `inference.js` — численные функции для t-критериев и p-value.
- `dependence.js` — расчёт корреляций и ранжирование для анализа зависимостей.
- `generator-model.js` — kNN-модель, оценка качества и разбиение выборки.
- `frequency-statistics.js` — EDA, нормализация и межквартильный размах.
- `components.js` — общие безопасные UI-компоненты.

## Подтверждённые данные

Объединённые CSV содержат 1599 красных и 4898 белых вин. Для `quality`: `N = 6497`, среднее `5.8183777`, медиана `6`, выборочная дисперсия `0.7625748`, стандартное отклонение `0.8732553`; частоты оценок 3–9 совпадают с `data.js`.

## Ограничения и риски

1. `app.js` содержит около 10 тыс. строк и несколько ответственностей.
2. `renderMethods` определена дважды; вторая версия переопределяет первую.
3. Node.js и Git недоступны в данной среде, поэтому их проверочные команды не запускаются.
4. Jupyter Notebook в папке проекта не предоставлен, поэтому сверка сделана с CSV и `data.js`.
