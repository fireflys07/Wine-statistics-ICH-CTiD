# План проверок Sprint 2

Реализация тестов появится вместе с генератором.
- Поддержка распределения, размер, тип результата, обработка неверных параметров.
- Повторяемость при фиксированном seed; изменение последовательности при другом seed.
- Проверка среднего и дисперсии с допусками, обоснованными ошибкой Монте-Карло.
- Критерий согласия с корректными ожидаемыми частотами и учётом оценённых параметров.
- Отдельная проверка независимости/автокорреляции последовательности.
Статистические тесты могут случайно отвергать верную модель; не делайте нестабильный CI на одном p-value.
