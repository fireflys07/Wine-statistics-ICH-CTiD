# Проверки

Из корня проекта после установки зависимостей:

```bash
python -m pytest -q
python scripts/run_notebooks.py
```

20 автотестов проверяют разделение повторов, регрессию, kNN, обратную функцию и отбор с отклонением.
Для генераторов проверяются границы интервалов, нулевые вероятности, допустимые значения,
размер, неверные параметры, воспроизводимость и частоты. Допуск частот равен шести стандартным ошибкам.

Ноутбук выполняется в отдельном чистом Jupyter-ядре. Результаты сохраняются только после успешного запуска.
Проверка автокорреляции последовательности пока не добавлена.
