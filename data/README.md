# Данные

Планируемый источник: UCI Wine Quality. Перед использованием проверьте карточку набора, лицензию и первичную публикацию; внесите ссылки и дату доступа в references/README.md.

Ожидаемые локальные файлы:
- `raw/winequality-red.csv`
- `raw/winequality-white.csv`

Формат: CSV с разделителем `;`, заголовками UCI (`volatile acidity` с пробелом).
Загрузчик переводит пробелы в подчёркивания и добавляет `wine_type`.
Исходные CSV не изменять. Запишите SHA-256, дату получения, источник и число строк.
Не удаляйте дубликаты автоматически: выясните, что они означают. Правила очистки фиксируйте до анализа.
CSV не включены в стартовый каркас. Исходные/производные данные игнорируются Git; отслеживаются инструкции по их получению.

## Sprint 2: подготовка alcohol → quality

Скачайте [исходный ZIP UCI](https://archive.ics.uci.edu/static/public/186/wine+quality.zip)
и извлеките `winequality-red.csv` и `winequality-white.csv` в `data/raw/`.
Проверенный источник получен 2026-11-02. Контрольные суммы показаны в выполненном ноутбуке.

Из корня репозитория установите окружение: `python -m pip install -e '.[dev]'`.
Откройте `notebooks/sprint2/00_data_split.ipynb` и выполните все ячейки.
Запускайте из корня репозитория или из папки ноутбука.
В Colab сначала клонируйте репозиторий и перейдите в его корень через `%cd`.

Ноутбук создаёт в `data/processed/`:
- `alcohol_quality_split.csv`: исходный идентификатор строки, SHA-256 группы, тип вина, train/test;
- `alcohol_quality_split.json`: seed, версии, источники и контрольные суммы CSV/manifest;
- `alcohol_quality_split_summary.csv`: размеры частей по типу вина.

Полные повторы сохраняются и всегда попадают в одну часть. Делятся группы по каждому
типу вина, приблизительно 80/20, seed=42. Не подбирайте seed по качеству модели.
Модель получает только alcohol; quality — цель. Все будущие преобразования и подбор
гиперпараметров должны обучаться внутри train. Test оставляем для финальной оценки.
Автотесты: `PYTHONPATH=src python -m unittest discover -s tests -v`.
