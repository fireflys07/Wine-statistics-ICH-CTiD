# Данные

Источник: [UCI Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality), DOI: 10.24432/C56S3T.
[Исходный архив](https://archive.ics.uci.edu/static/public/186/wine+quality.zip). Получен 2026-11-13.

Из корня проекта:

```bash
python scripts/download_data.py
```

| Файл | Строки | SHA-256 |
|---|---:|---|
| winequality-red.csv | 1599 | 4a402cf041b025d4566d954c3b9ba8635a3a8a01e039005d97d6a710278cf05e |
| winequality-white.csv | 4898 | 76c3f809815c17c07212622f776311faeb31e87610d52c26d87d6e361b169836 |

Файлы сохраняются без изменений в `data/raw/`. Разделитель `;`.
Загрузчик заменяет пробелы в названиях на подчёркивания и добавляет `wine_type`.
В первом спринте quality и acidity используют локальные псевдонимы столбцов исходных рабочих ноутбуков.

В объединённом наборе 6497 строк, пропусков нет, полных повторов сверх первых вхождений 1177.
Повторы сохраняются: неизвестно, отражают ли они повторные измерения или дубли записи.
CSV и производные разбиения игнорируются Git, их можно получить повторно.

`00_data_split.ipynb` записывает manifest и метаданные в `data/processed/`.
При seed=42 получается 5195 строк train и 1302 строки test. Совпадающие полные строки
остаются в одной части. Внутреннее разбиение на fit/validation использует seed=43.
Результаты проверяются по хешам исходных файлов и повторному построению manifest.
